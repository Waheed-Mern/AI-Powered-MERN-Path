# Responsive AI-Powered MERN Profile Card

A modern, fully responsive profile card built with semantic HTML5 and CSS3. This project demonstrates core frontend concepts learned over a 10-day intensive practice period.

## 🚀 Features
- **Semantic HTML5:** Used `header`, `main`, and `footer` for better SEO and structure.
- **CSS Variables:** Implemented a global color palette using `:root`.
- **Flexbox Mastery:** Used Flexbox for navigation and card alignment.
- **Advanced Positioning:** Implemented an "Online Status Dot" using absolute positioning.
- **Responsive Design:** Fully optimized for Desktop, Tablet (768px), and Mobile (480px).
- **Interactive UI:** Scrollable bio section and hoverable capsules.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Custom Variables, Flexbox, Media Queries)
- Google Fonts (Inter)
