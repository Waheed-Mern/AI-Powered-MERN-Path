# Project: ES6+ Syntax Mastery - Destructuring & Spread/Rest Operators

### Objective
To implement modern JavaScript syntax patterns to write cleaner, more concise, and more readable code, specifically focusing on array/object manipulation and immediate asynchronous execution.

### Logic Flow
1. **Asynchronous IIFE:** Using an Immediately Invoked Function Expression `(async function main() { ... })()` to run `await` logic without needing a separate global call.
2. **Rest Operator (`...rest`):** Capturing the "remaining" elements of an array into a new sub-array during assignment.
3. **Object Destructuring:** Extracting specific properties from an object directly into variables, reducing the need for `obj.property` repetitive calls.
4. **Spread Operator (`...arr`):** "Unpacking" an array into individual arguments for a function call.
5. **Hoisting & Scope:** Observing the behavior of `var` and global declarations outside the async block.

### The Foundation
In React, when you receive data (props), you use **Destructuring** to pull out exactly what you need. When you update a state (like a shopping cart), you use the **Spread Operator** to copy the old array and add new items. These are not just "shortcuts"; they are the industry standard for writing professional MERN applications.
