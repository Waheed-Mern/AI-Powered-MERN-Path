# Day 03: CSS Box Model & Viewport Units 📐

### Overview
Today I explored the core of CSS layout design: the Box Model and Responsive Sizing Units. I practiced how elements occupy space and how to make them fluid across different screen sizes.

### Key Learnings:
- **Box Sizing:** Used `box-sizing: border-box` to ensure padding and borders don't break the layout width.
- **Viewport Units:** - `vw` & `vh`: Sizing relative to the screen width and height.
  - `vmin` & `vmax`: Advanced responsive units for better scaling on mobile/tablet.
- **Child Combinators:** Targeted specific nested elements using the `>` selector (e.g., `.w > div > div`).
- **Centering:** Used `margin: auto` for horizontal centering of block elements.

### Visual Experiment:
Implemented nested containers with different border colors (Blue and Red) to visualize how child widths are calculated relative to their parent's width.
