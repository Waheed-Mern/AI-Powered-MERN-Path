# 🚀 Day 21: Probabilistic Logic - The Faulty Calculator

## 📌 Technical Summary
Today I successfully built a functional "Faulty Calculator" that leverages JavaScript's randomization and dynamic execution capabilities. This project highlights my ability to handle user input and transform it into executable logic.

### 🧠 Key Engineering Implementations:
- **Randomization Control:** Used `Math.random()` to set a 0.1 threshold, simulating a 10% error rate.
- **Dynamic Operator Swapping:** Mapped user input to a 'faulty' operator object to manipulate calculation results.
- **Template Literals:** Used `${}` for clean string interpolation, making the code more readable and maintainable.
- **Dynamic Execution:** Utilized `eval()` to parse and execute mathematical strings directly from variable inputs.

### 🛠️ Key Learning:
Mastered the concept of **String Interpolation** and how to manipulate data flows before they reach the execution phase.
