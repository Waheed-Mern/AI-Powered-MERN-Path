# Day 06: CSS Overflow & Viewport Units 📦

### Key Learnings:
1. **Overflow Management:** Learned how to handle content spillover using `auto`, `scroll`, and `hidden`.
2. **Viewport Units:** Used `vw` and `vh` for fluid box sizing instead of fixed pixels.
3. **Text Truncation:** Experimented with `white-space: nowrap` and `text-overflow` to control long strings of text.
