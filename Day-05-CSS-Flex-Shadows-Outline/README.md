# Day 05: Navigation Layouts, Shadows & Outlines 🚀

### Key Learnings:
1. **Flexbox Intro:** Used `display: flex` on `ul` to align navigation items horizontally.
2. **Visual Effects:** - Implemented `box-shadow` for card-like elevation.

3. **Advanced Box Model:** Practiced the difference between `outline` and `border`.
