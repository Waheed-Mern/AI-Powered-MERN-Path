# 🚀 Day 17: JavaScript Fundamentals & Core Concepts

## 📌 Technical Summary
Today marks the start of my JavaScript journey within the MERN stack. I focused on understanding how the browser executes scripts, interacts with the user via BOM (Browser Object Model), and manages data using different variable scopes and types.

### 🧠 Key Engineering Implementations:
- **User Interaction (BOM):** Implemented `alert()`, `prompt()`, and `confirm()` for basic user input and browser-level feedback.
- **DOM Manipulation:** Dynamically updated the page metadata using `document.title`.
- **Variable Scoping (ES6+):** - Analyzed the difference between `var` (function-scoped) and `let` (block-scoped).
    - Demonstrated block-level isolation where a variable inside `{}` does not leak to the outer scope.
- **Primitive Data Types:** Explored `string`, `number`, `boolean`, `undefined`, and `null`.
- **Non-Primitive (Objects):** Created a dynamic object to store key-value pairs and demonstrated how to mutate object properties (e.g., updating salary).

### 🛠️ Performance & Best Practices:
Learned the importance of `typeof` for debugging and why modern JS development favors `let` and `const` over `var` to prevent global scope pollution.
