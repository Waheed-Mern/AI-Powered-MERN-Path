# Day 09: Global Theming with CSS Variables 🎨

Today I explored CSS Variables (Custom Properties) and how they make code maintainable and professional.

### Key Takeaways:
- **:root Selector:** Declaring global variables that can be accessed throughout the stylesheet.
- **CSS Variables (`--var-name`):** Storing reusable values for colors, padding, and opacity.
- **Flexbox Navigation:** Using `display: flex` on list items for a horizontal menu.
- **nth-child Selector:** Targeted specific elements (like the second paragraph) to apply unique styles using `var(--defop)`.

### Why use Variables?
Instead of changing colors in 50 different places, I can now change them once in `:root`, and the entire website updates automatically!
