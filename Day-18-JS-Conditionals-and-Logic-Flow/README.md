# 🚀 Day 18: Logic Flow & Decision Making in JavaScript

## 📌 Technical Summary
Today I focused on building dynamic logic within JavaScript. I explored how to control the execution flow of a program based on specific conditions and user input.

### 🧠 Key Engineering Implementations:
- **Type Casting/Conversion:** Used `Number(prompt())` to ensure string inputs from the user are treated as integers for mathematical comparisons.
- **Conditional Branching:** Implemented `if`, `else if`, and `else` structures to handle multiple logical scenarios.
- **Arithmetic Operators:** Practiced standard operations including Exponentiation (`**`) and Modulus (`%`).
- **The Ternary Operator:** Refactored standard `if-else` blocks into concise, single-line logic using the `condition ? true : false` syntax—a crucial skill for React development.
- **Comparison Logic:** Experimented with relational operators (`>=`, `==`, `>`) to validate data.

### 🛠️ Best Practices:
- Utilized both single-line and multi-line comments for better code documentation.
- Practiced logical thinking by handling "Edge Cases" (e.g., checking if age is 0 or 1).
