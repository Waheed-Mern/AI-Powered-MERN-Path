# Day 08: Responsive Card UI Design 🎨

Today I built a professional Product Card UI, focusing on layout structure and visual aesthetics using CSS.

### Key Learnings:
- **Flexbox Centering:** Used `display: flex` on the body to position the card.
- **Modern Sizing:** Implemented `width: min(90%, 300px)` for perfect responsiveness on all screens.
- **Visual Effects:** Added `box-shadow` with custom colors to create depth.
- **Component Styling:** Created "Capsules" (Tags) and styled buttons with hover transitions.

### Tech Stack:
- HTML5 (Semantic containers like `.card`, `.content`)
- CSS3 (Flexbox, Border-radius, Box-shadow, Transitions)
