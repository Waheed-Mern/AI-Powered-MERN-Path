# Project: Advanced Data Transformation & Iteration

### Objective
To implement and understand high-order array methods (Map, Filter, Reduce) and various iteration patterns for both Arrays and Objects in JavaScript.

### Logic Flow
The script demonstrates the full lifecycle of data handling:
1. **Mutation & Access:** Modifying array elements by index and measuring length.
2. **Formatting:** Converting arrays to strings and custom-joined formats.
3. **Splicing:** Using `splice()` for complex operations (deleting and injecting elements simultaneously).
4. **Iteration Diversity:** - Standard `for` loop for manual control.
   - `forEach` for side effects.
   - `for...in` and `for...of` for object/key-value traversal.
5. **Functional Programming:** Implementing `map` for transformation, `filter` for conditional extraction, and `reduce` for data aggregation.

### The Foundation
In AI-integrated apps, you often receive "Raw Data" (JSON) from an API. Mastering `map` and `filter` is non-negotiable for React developers, as these methods are used to render lists and search through datasets. Without understanding `reduce`, complex state management (like Redux or calculating shopping cart totals) becomes impossible.
